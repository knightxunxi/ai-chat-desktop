# CodeXX v1.0 Agent 场景验收脚本

> 创建日期：2026-07-04
> 目标：模拟真实用户使用 Agent 的典型路径，覆盖核心交互流程
> 执行方式：逐条发送到输入框，观察 Agent 行为和 UI 表现

---

## 场景一：文件创建与编辑

```text
# 发送：
在工作目录创建一个 "demo.md"，写入以下内容：
## 测试标题
这是一段测试内容。
```

**预期验证：**
- [ ] Agent 调用 `workspace.write_text` 创建 `demo.md`
- [ ] 文件内容正确
- [ ] Agent 步骤卡片展示"Step 1/1"
- [ ] 最终回复确认创建成功

---

## 场景二：多步文件操作

```text
# 发送：
1. 读取 demo.md 的内容
2. 在 demo.md 末尾追加一行 "=== 追加内容 ==="
3. 再次读取 demo.md 确认追加成功
```

**预期验证：**
- [ ] Agent 按顺序执行 3 步（read → append → read）
- [ ] 最终读取结果包含追加行
- [ ] 步骤分组显示 "Completed: 3 steps"
- [ ] 无失败步骤

---

## 场景三：搜索 + 读取

```text
# 发送：
在 src/app/ 目录中搜索 "AgentLoopController" 关键字，
并读取搜索结果中第一个文件的类定义
```

**预期验证：**
- [ ] 调用 `file.grep` 搜索
- [ ] 调用 `file.read_text` 读取
- [ ] 最终回复包含 AgentLoopController 类定义描述
- [ ] 观察工具栏数量减少模式（不是 10+ 工具连续执行）

## 场景四：构建 + 测试

```text
# 发送：
运行 cmake --build build 构建，然后执行 ctest 运行测试
```

**预期验证：**
- [ ] Agent 调用 `command.bash` 执行构建
- [ ] 构建输出展示（成功/失败/警告）
- [ ] Agent 调用 `command.ctest` 执行测试
- [ ] 测试结果展示（通过数/失败数）
- [ ] 整个过程无 UI 冻结

## 场景五：工具失败恢复

```text
# 发送：
执行一个不存在的命令 "nonexistent_command_xyz"
然后列出当前工作目录的文件
```

**预期验证：**
- [ ] 第一个命令执行失败
- [ ] Agent 观察失败原因
- [ ] 第二个命令（ls 目录）正常运行
- [ ] 最终回复包含文件列表和失败说明
- [ ] Agent 不会因为一次失败就终止整个循环
