# V7 Agent 安全设计

本文档对应 V7-TASK-001，用于定义 AI Chat Desktop 的受控 Agent 安全边界。V7 的目标是让 AI 能够生成任务计划和建议工具调用，但不允许 AI 绕过用户确认直接操作电脑。

执行状态：V7 安全设计已建立，当前开发已实现工具目录、计划解析器、计划生成入口、计划预览窗口和低风险文本工具单步执行。

## 1. 核心原则

- AI 只负责建议：AI 可以生成结构化计划和建议工具 ID，但不能直接执行工具。
- 本地负责校验：所有计划必须经过本地解析器校验，不能信任模型输出。
- 用户负责确认：每一步工具调用前都需要用户确认。
- 工具负责执行：工具执行逻辑仍由现有 C++ 模块完成，Agent 不拼接脚本或命令。
- 日志负责追踪：记录计划 ID、步骤 ID、工具 ID、确认状态和执行结果摘要，不记录敏感正文。

## 2. V7 允许的能力

| 能力 | 说明 |
| --- | --- |
| 生成任务计划 | AI 返回 JSON 格式计划 |
| 建议工具调用 | AI 只能选择工具目录中的工具 ID |
| 展示计划步骤 | UI 展示每一步标题、原因、参数和风险等级 |
| 用户确认执行 | 每一步执行前等待用户确认 |
| 单步工具执行 | 用户确认后执行低风险工具 |
| 结果展示 | 工具结果先展示给用户 |
| 结果回传确认 | 用户确认后才允许把工具结果发给 AI |

## 3. V7 禁止的能力

V7 明确不做：

- Shell、PowerShell、CMD 命令执行。
- 任意脚本运行。
- 键盘、鼠标或设备输入模拟。
- 后台无人值守执行。
- 自动读取未由用户选择的路径。
- 自动删除、移动、重命名或覆盖文件。
- 自动上传文件内容或工具结果给 AI。
- 绕过工具目录执行模型生成的任意动作。
- 在日志中记录文件正文、聊天正文、API Key、Token 或完整目录。

## 4. 工具目录策略

进入 Agent 建议范围的工具必须具备：

- 稳定工具 ID。
- 中文/英文名称。
- 用途说明。
- 输入限制。
- 风险等级。
- 是否需要用户确认。
- 结果是否可能包含敏感信息。

风险等级：

| 等级 | 含义 |
| --- | --- |
| low | 只处理用户提供的文本，不访问文件系统 |
| medium | 可能读取或展示本地路径、文件内容或目录信息 |
| high | 可能修改系统、执行命令或影响外部环境 |

V7 默认只允许 `low` 和受控 `medium` 工具进入建议范围。`high` 工具不进入 V7。

## 5. 计划结构要求

AI 返回内容必须是 JSON 对象：

```json
{
  "summary": "计划摘要",
  "steps": [
    {
      "id": "step-1",
      "title": "步骤标题",
      "toolId": "json.format",
      "reason": "为什么需要这一步",
      "risk": "low",
      "parameters": {}
    }
  ]
}
```

本地解析器必须校验：

- 根节点必须是对象。
- 允许从常见 Markdown 代码块或少量说明文字中提取 JSON 对象，但提取后仍必须满足完整 schema。
- `summary` 必须是非空字符串。
- `steps` 必须是非空数组。
- 步骤数量不能超过上限，默认 5 步。
- 每一步必须包含 `id`、`title`、`toolId`、`reason`、`risk`。
- `toolId` 必须存在于工具目录。
- `risk` 必须是 `low`、`medium` 或 `high`。
- `parameters` 如果存在，必须是对象。
- AI 标注的风险如果低于工具目录风险，以工具目录风险为准。

## 6. 用户确认策略

每个步骤至少有三种用户动作：

- 执行：确认当前步骤。
- 跳过：不执行当前步骤，进入下一步或结束。
- 停止：终止整个计划。

涉及文件或可能包含敏感结果的步骤，需要额外提醒：

- 展示工具 ID。
- 展示参数。
- 展示风险等级。
- 展示结果可能包含的敏感信息类型。

## 7. 结果回传策略

工具结果默认只展示给用户，不自动发给 AI。

允许回传前必须满足：

- 用户明确点击确认。
- UI 展示将要回传的结果摘要。
- 日志只记录回传动作和长度，不记录完整正文。

## 8. 日志策略

V7 日志可以记录：

- 计划生成开始和结束。
- 计划解析成功或失败。
- 计划 ID。
- 步骤 ID。
- 工具 ID。
- 用户确认、跳过、停止动作。
- 工具执行成功或失败。
- 输出长度和错误摘要。

V7 日志禁止记录：

- 文件正文。
- 聊天正文。
- API Key、Token、密码。
- 完整文件路径。
- 工具完整输出。

## 9. 测试策略

自动化测试应覆盖：

- 工具目录 ID 唯一。
- 工具目录风险等级有效。
- 合法计划可以解析。
- 非 JSON 计划失败。
- Markdown 代码块包裹的 JSON 计划可以提取并校验。
- 缺字段计划失败。
- 未知工具 ID 失败。
- 步骤过多失败。
- 非法风险等级失败。
- `parameters` 不是对象时失败。
- AI 标注低风险但工具目录为中风险时，本地提升为中风险。

UI 和真实 AI 调用可在后续任务中补充 smoke test 和手工验收。

- Agent 计划解析测试。

- Agent 低风险步骤执行测试。
- Agent 计划窗口 smoke test。
