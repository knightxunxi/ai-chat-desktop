## 三、待开发路线 — 按可行性与优先级排序

### V19 方向校准（2026-07-03）

下一阶段从“单纯多厂商适配层”升级为“Python Agent 能力层 sidecar”。这不是第二套 Agent 流程，也不是把工具执行迁移到 Python；C++ 继续保留 UI、会话、Agent 循环、工具注册和本机权限边界，Python 只负责更适合生态库扩展的能力层。

分支策略：

| 分支 | 作用 |
|------|------|
| `baseline/cpp-agent-v1.0` | 保留当前 C++ v1.0 基线，便于回滚和继续纯 C++ 方向优化 |
| `feature/python-agent-capability-layer` | 开发 Python sidecar、AI backend 抽象、多厂商适配、token 统计、Web/文档/浏览器能力 |

优先级调整：

1. 先做 Python sidecar JSONL 协议骨架和测试。
2. 再做 C++ `QProcess` sidecar client，不直接改动 Agent 主循环。
3. 稳定后增加 `PythonSidecarAIClient`，作为 `AIClient` 的可选实现。
4. 最后接入多厂商适配、精确 tokenizer、WebSearch、文档解析和 Playwright 浏览器能力。
