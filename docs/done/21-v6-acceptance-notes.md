## 3. 新增代码能力

新增文件交互服务：

```text
src/tools/FileInteractionService.h
src/tools/FileInteractionService.cpp
```

核心能力：

- `readTextFile`：读取文本文件，默认最大 1 MiB。
- `listDirectory`：列出目录条目，默认最多 200 条。
- `saveTextFile`：保存文本到指定文件，未确认时拒绝覆盖。
- `validateOpenPath`：打开文件或目录前校验路径存在。
- `pathSummary`：生成日志用路径摘要，不暴露完整目录。

新增文件工具窗口：

```text
src/ui/FileToolsDialog.h
src/ui/FileToolsDialog.cpp
```

UI 能力：

- 使用文件选择框选择文件或目录。
- 展示读取结果或目录列表。
- 支持保存、复制、插入聊天输入框。
- 打开文件或目录前需要确认。
- 不自动把工具输出发送给 AI。

- 主窗口顶部“文件工具”按钮可以打开文件工具窗口。
- 读取文本文件后内容显示在输出区。

- 复制输出可用。
- 插入聊天输入框可用，且不会自动发送。
- 日志中有文件交互操作记录，但没有文件正文。

## 7. 风险和遗留项

当前仍保留的限制：

- 文件工具只处理用户主动选择的路径。
- 文本读取默认最大 1 MiB。
- 二进制文件只做基础 NUL 字节识别。
- 目录列表默认最多展示 200 条。
- 暂不支持删除、移动、批量写入或脚本执行。
- 暂不支持 AI 自动调用文件工具。

这些限制是有意保留的，目的是先建立可验证的本地交互边界，再进入 Agent 执行循环。
