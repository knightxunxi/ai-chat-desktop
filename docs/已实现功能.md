## 1. 总体状态

当前项目已经从 Qt6 聊天客户端演进为桌面 AI Agent 编程助手。主线能力包括聊天、Agent 循环、工具执行、记忆、Skills、Hooks、MCP、调度、Python sidecar、插件预留、跨平台抽象和发布验收文档。

当前已完成主线：

- Qt6 Widgets 桌面聊天与 Markdown 渲染。
- OpenAI-compatible API 接入，DeepSeek/OpenAI/自定义服务商配置。
- 单一 Agent 主循环：分析 -> 工具执行 -> 观测 -> 继续。
- 60+ Agent 工具注册与 Function Calling 执行链路。
- Python sidecar 能力层，可承载模型、多厂商、Token、Web、文档和浏览器能力。
- 三层记忆、Skills、Hooks、MCP、Cron 调度、会话恢复、对话分支。
- v1.0 发布验收文档、打包报告和场景脚本。
