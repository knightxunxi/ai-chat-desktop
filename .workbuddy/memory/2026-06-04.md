## V17.1 BugFix: 图片未发送给 API 大模型 + 预览 UI 优化 (21:24)

### 问题1：图片未发送到 API（P0）

**根因**: `ApplicationController::sendMessageWithImages()` 在调用 `sendChatWithImages()` 之前追加了空的 Assistant 占位消息（第364行）。`buildRequestBody()` 用 `&message == &session.messages.last()` 判断"最后一条 User 消息"，但此时最后一条是 Assistant 占位，导致图片信息被**静默丢弃**。

**修复**: 在 `OpenAICompatibleClient::buildRequestBody()` 中改为扫描找到**最后一条 User 消息的索引**：
- 遍历前先找 `lastUserIndex`（跳过空内容的 User 消息）
- 循环中用 `msgIndex == lastUserIndex` 替代 `&message == &session.messages.last()`

**影响文件**: `src/services/OpenAICompatibleClient.cpp`（~10行改动）

### 问题2：图片预览栏 UI 优化

**改动前**: 100x100 大缩略图框体，带 × 按钮和右键菜单
