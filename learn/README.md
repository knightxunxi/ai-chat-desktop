# AI Chat Desktop 学习资料

这个目录用于从学习和简历准备角度复盘本项目。它不是运行说明，而是帮助你理解：

- 项目为什么这样分层。
- 每个技术点解决了什么问题。
- 代码从界面到网络请求再到本地存储是怎样流动的。
- 面试中可能被问到哪些问题，以及如何回答。

## 和 docs 目录的区别

`docs/` 更像企业开发过程中的过程文档，包括需求、设计、任务拆分、验收和发布说明。

`learn/` 更偏向个人学习总结和面试复盘，重点回答三个问题：

- 这个项目怎么讲清楚。
- 这些技术为什么用。
- 被追问实现细节时怎么回答。

## 建议学习方式

第一遍先看架构和流程，形成整体地图。

第二遍对照源码看技术讲解，例如：

- `src/ui` 看 Qt Widgets 界面。
- `src/app` 看控制层如何组织业务。
- `src/services` 看网络请求和流式解析。
- `src/storage` 看本地持久化和凭据存储。
- `tests` 看自动化测试如何覆盖核心逻辑。

第三遍用面试问答训练表达。回答时不要只背技术名词，要尽量说清楚：

- 背景是什么。
- 遇到的问题是什么。
- 你怎么设计。
- 为什么这样设计。
- 最后如何验证。
