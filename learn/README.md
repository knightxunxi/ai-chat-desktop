# CodeXX (AI Chat Desktop) 学习资料

这个目录用于从学习和面试准备角度复盘本项目。它不是运行说明，而是帮助你理解：

- 项目为什么这样分层。
- 每个技术点解决了什么问题。
- 代码从界面到网络请求再到 Agent 工具是怎样流动的。
- 面试中可能被问到哪些问题，以及如何回答。

## 阅读顺序

建议按下面顺序看：

1. [项目架构说明](01-architecture.md) — 分层结构、模块职责、v1.0 整体架构
2. [关键业务流程](02-key-flows.md) — 26 个流程（Chat + Agent + 记忆 + 桌面自动化）
3. [技术栈讲解](03-technology-notes.md) — 22 个技术点 + **8 项设计决策取舍** + 代码阅读指南
4. [简历项目表达](04-resume-guide.md) — 项目描述、STAR 故事、关键词
5. [面试问题预测与参考答案](05-interview-qa.md) — 54 道题（含 11 道 Agent 专题）

## 文档层次

```
01-architecture    → WHAT   — 结构是什么，有什么模块
02-key-flows       → HOW    — 数据/控制怎么流动
03-technology-notes → WHAT + WHY + TRADE — 用什么技术、为什么选它、替代方案是什么
04-resume-guide    → TALK   — 怎么讲给面试官
05-interview-qa    → ANSWER — 怎么回答追问
```

## 和 docs 目录的区别

`docs/` 更像企业开发过程中的过程文档，包括需求、设计、任务拆分、验收和发布说明。

`learn/` 更偏向个人学习总结和面试复盘，重点回答三个问题：

- 这个项目怎么讲清楚。
- 这些技术为什么用。
- 被追问实现细节和架构决策时怎么回答。

## 建议学习方式

第一遍先看架构（01）和流程（02），形成整体地图。

第二遍对照源码看技术讲解（03），重点关注"代码阅读指南"——按推荐顺序从外到内阅读关键源文件。**设计决策与取舍**部分是面试核心弹药，理解每个决策的"替代方案→为什么没选→代价是什么"。

第三遍用面试问答（05）训练表达。回答时不要只背技术名词，要尽量说清楚：

- 背景是什么。
- 遇到的问题是什么。
- 你怎么设计。
- 为什么这样设计（替代方案是什么，为什么没选）。
- 最后如何验证。
